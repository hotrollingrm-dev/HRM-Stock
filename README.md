# HRM STOCK CONTROL MANAGEMENT · เว็บแอปบน Vercel

หน้าเว็บเหมือนฉบับ Google ทุกอย่าง และใช้ข้อมูลชุดเดียวกัน ข้อมูลยังอยู่ใน Google Sheet เดิม
ส่วน Vercel ทำหน้าที่ 2 อย่าง คือแสดงหน้าเว็บ และส่งต่อคำสั่งไปยัง Apps Script ผ่าน `/api`

```
เบราว์เซอร์ ──► Vercel (public/ + api/[name].js) ──► Apps Script /exec ──► Google Sheet
                                       ▲ GAS_KEY = WEB_KEY (รหัสลับที่ต้องตรงกัน)
```

## ติดตั้งครั้งแรก (ประมาณ 15 นาที)

### 1. ฝั่ง Google Apps Script (ทำครั้งเดียว)
1. วางโค้ด v3.16 ทับไฟล์เดิมใน Apps Script ให้ครบทั้ง 5 ไฟล์ แล้วกดบันทึก
2. เลือกฟังก์ชัน `makeWebKey` แล้วกด ▶ Run
3. เปิด "บันทึกการดำเนินการ" (Execution log) แล้วคัดลอกค่าในบรรทัด `GAS_KEY สำหรับ Vercel = …` เก็บไว้
4. Deploy เป็นเวอร์ชันใหม่: Deploy › จัดการการทำให้ใช้งานได้ › ✏️ › เวอร์ชัน: ใหม่
   - ผู้มีสิทธิ์เข้าถึงต้องเป็น "ทุกคน" เหมือนเดิม
5. คัดลอกลิงก์เว็บแอปที่ลงท้ายด้วย `/exec` เก็บไว้

### 2. อัปโหลดขึ้น GitHub
1. ไปที่ github.com แล้วกด New repository
   - ตั้งชื่อ เช่น `hrm-stock-web`
   - เลือก **Private**
2. กด "uploading an existing file" แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป
   - ไฟล์ที่ต้องมี: `api/`, `public/`, `vercel.json`, `package.json`, `README.md`, `.gitignore`, `.env.example`
3. กด Commit changes

### 3. เชื่อม Vercel
1. เข้า vercel.com ด้วยบัญชี GitHub
2. ไปที่ Add New… › Project › Import repo `hrm-stock-web`
3. Framework Preset เลือก **Other** ไม่ต้องตั้ง Build Command
4. ที่ Environment Variables ให้เพิ่ม 3 ค่า:

   | Name | Value |
   |---|---|
   | `BACKEND` | `gas` |
   | `GAS_URL` | ลิงก์ `/exec` จากขั้นที่ 1.5 |
   | `GAS_KEY` | ค่าที่คัดลอกไว้ในขั้นที่ 1.3 |
   | `TEAM_CODE` | รหัสทีมที่ทุกคนใช้เข้าเว็บ (อย่างน้อย 6 ตัว) — ไม่ใส่ = ไม่มีหน้าเข้าสู่ระบบ |

5. กด Deploy แล้วจะได้ลิงก์ เช่น `https://hrm-stock-web.vercel.app`

### 4. ใช้งาน
- **เปิดใช้งาน:** เปิดลิงก์ Vercel ได้ทั้งคอมพิวเตอร์และมือถือ ระบบเลือกหน้าจอให้อัตโนมัติ
- **Widget:** ใช้ลิงก์ `https://…vercel.app/?view=widget` หรือใส่ลิงก์ Vercel ในโปรแกรม HRMStockWidget.exe
- **LINE:** ปุ่มในการ์ด LINE จะเปิดลิงก์ Vercel ให้เอง โดยระบบจำลิงก์ไว้ตั้งแต่ครั้งแรกที่มีคนเปิดเว็บ
  - Webhook ของ LINE ยังต้องเป็นลิงก์ `/exec` เหมือนเดิม
- **โหมด Officer และรหัส PIN:** ใช้ชุดเดิมจากฉบับ Google

## รหัสทีม (หน้าเข้าสู่ระบบ)
- **ตั้งรหัส:** Vercel › Settings › Environment Variables › เพิ่ม `TEAM_CODE` แล้ว Redeploy
- **การจำเครื่อง:** เปิดเว็บครั้งแรกต้องใส่รหัสทีม 1 ครั้ง แล้วเครื่องนั้นจะจำไว้ 30 วัน
- **คนที่ไม่มีรหัส:** เปิดลิงก์ได้แค่หน้าใส่รหัส ข้อมูล STOCK ทุกอย่างจะถูกระบบฝั่ง Vercel ปฏิเสธ
- **เปลี่ยนรหัส:** แก้ `TEAM_CODE` แล้ว Redeploy ทุกเครื่องจะถูกออกจากระบบ ต้องใส่รหัสใหม่
- **ออกจากระบบบนเครื่องเดียว:** ตั้งค่า › ประวัติการใช้งาน › ปุ่ม **ออกจากระบบ**
- **ลิงก์ `/exec` เดิม:** ตั้งแต่ v3.19 เมื่อเปิดเว็บ Vercel ครั้งแรก ลิงก์ `/exec` จะพาไปหน้า Vercel ให้เอง ทุกทางจึงต้องผ่านรหัสทีม
  - LINE webhook ยังใช้ลิงก์ `/exec` ได้ตามปกติ
  - ถ้า Vercel ล่ม และต้องการเปิด `/exec` ใช้ตรงๆ ชั่วคราว: ไปที่ Apps Script › Project Settings › Script Properties › เพิ่ม `EXEC_OPEN` = `1` (ลบออกเมื่อเลิกใช้)

## QR สำหรับมือถือ
ตั้งค่า › การ์ด **QR เปิดใช้งานบนมือถือ** มี QR 2 แบบ และกดปุ่ม **พิมพ์ QR** เพื่อพิมพ์เป็นแผ่น A4 ได้
- **QR ต้องใส่รหัสทีม:** เป็นลิงก์ปกติ สแกนแล้วต้องใส่รหัสทีม ติดไว้หน้างานได้
- **QR เข้าได้เลย:** Officer สร้างได้ เลือกอายุได้ 1, 7, 30 หรือ 90 วัน สแกนแล้วเข้าใช้ได้ทันทีโดยไม่ต้องพิมพ์รหัส
  - ส่งให้เฉพาะคนในทีม และอย่าติดไว้ในที่ที่คนนอกเห็น
  - ยกเลิก QR ทุกอันได้ด้วยการเปลี่ยน `TEAM_CODE` แล้ว Redeploy

## แจ้งเตือนบนมือถือ (Push)
- **เปิดใช้งาน:** ในหน้ามือถือกดไอคอนกระดิ่ง 🔔 มุมขวาบน (ในหน้าคอมพิวเตอร์อยู่ที่ ตั้งค่า › การ์ด **แจ้งเตือนบนเครื่องนี้**)
  - เลือกทีม A, B, C หรือทุกทีม แล้วกด **เปิดแจ้งเตือน** จากนั้นกด **ทดสอบ** เพื่อลองเด้งเตือน
- **เวลาที่เด้งเตือน:** ถ้าเลยเวลาเตือน (19:45) แล้วกะเช้ายังไม่ลง STOCK
  - เครื่องที่เลือกทีมนั้นหรือเลือกทุกทีมจะได้รับแจ้งเตือน วันละ 1 ครั้ง แม้ไม่ได้เปิดแอปอยู่
  - กดที่การแจ้งเตือนแล้วจะเปิดหน้ากรอก STOCK
- **iPhone:** ต้องเพิ่มลงหน้าจอโฮมก่อน แล้วเปิดแอปจากไอคอน ใช้ได้กับ iOS 16.4 ขึ้นไป
- **ไม่ต้องตั้งค่าเพิ่ม:** ระบบสร้างกุญแจแจ้งเตือนจาก `GAS_KEY` ให้เอง
  - ถ้าเปลี่ยน `GAS_KEY` มือถือทุกเครื่องต้องเปิดแจ้งเตือนใหม่
- **ข้อมูลที่ระบบเก็บ:** รายชื่อเครื่องที่เปิดแจ้งเตือนอยู่ในแผ่น `push_sub` ของ Google Sheet ระบบลบเครื่องที่เลิกใช้ออกให้เอง

## ติดตั้งเป็นแอปบนมือถือ (PWA)
- **Android (Chrome):** เปิดลิงก์ Vercel แล้วจะมีแถบ "ติดตั้ง HRM STOCK เป็นแอป" ขึ้นด้านบน ให้กด **ติดตั้ง**
  - ถ้าไม่มีแถบขึ้น ให้กดเมนู ⋮ › **ติดตั้งแอป** หรือ **เพิ่มไปยังหน้าจอหลัก**
- **iPhone (Safari):** แตะปุ่มแชร์ ⎙ แล้วเลือก **เพิ่มไปยังหน้าจอโฮม**
- **คอมพิวเตอร์ (Chrome / Edge):** คลิกไอคอนติดตั้ง ⊕ ที่ช่องลิงก์ด้านบน
- **หลังติดตั้ง:** ได้ไอคอน HRM STOCK บนหน้าจอ เปิดแล้วเต็มจอเหมือนแอปทั่วไป
  - กดไอคอนค้างเพื่อเปิดทางลัดได้ 3 ทาง: **กรอก STOCK**, **สต็อกคงเหลือ** และ **Widget**
- **ตอนไม่มีอินเทอร์เน็ต:** แอปยังเปิดได้ แต่จะขึ้นหน้า "ไม่มีอินเทอร์เน็ต" และเข้าระบบให้เองเมื่อเน็ตกลับมา
  - ข้อมูลไม่ถูกเก็บไว้ในเครื่อง ทุกครั้งที่เปิดจึงเห็นข้อมูลล่าสุดจาก Google Sheet

## อัปเดตเวอร์ชันถัดไป
- อัปโหลดไฟล์ในโฟลเดอร์ `public/` ใหม่ทับใน GitHub แล้ว Vercel จะ Deploy ให้เองภายในประมาณ 1 นาที
- แอปที่ติดตั้งไว้แล้วจะอัปเดตเองตอนเปิดครั้งถัดไป ไม่ต้องติดตั้งใหม่
- ถ้า `Code.gs` มีการเปลี่ยนแปลง ต้องวางโค้ดใหม่ใน Apps Script แล้ว Deploy เวอร์ชันใหม่ด้วย

## ความปลอดภัย
- `GAS_KEY` ต้องเก็บไว้ใน Vercel Environment Variables เท่านั้น ห้ามใส่ลงในไฟล์ใน repo
- repo ต้องเป็น **Private**
- ห้ามแชร์ลิงก์ `/exec` และลิงก์ Vercel นอกทีม
- ต้องเปลี่ยน PIN ของ Officer จากค่าเริ่มต้น 1234
- ถ้ารหัสลับหลุด ให้ลบ `WEB_KEY` ใน Apps Script › Project Settings › Script Properties
  - จากนั้นรัน `makeWebKey` เพื่อสร้างรหัสใหม่
  - แล้วแก้ค่า `GAS_KEY` ใน Vercel และกด Redeploy

## ข้อจำกัด
- ไฟล์ที่ส่งหรือรับในแต่ละครั้ง (รูปสแกน หรือ PDF ที่ export) ต้องไม่เกินประมาณ 4 MB ตามข้อจำกัดของ Vercel
  - ถ้าไฟล์ใหญ่กว่านี้ ให้ใช้ลิงก์ `/exec` แทน
- Vercel แบบฟรีรอคำตอบได้นานสุด 60 วินาทีต่อครั้ง ซึ่งพอสำหรับทุกหน้า
- `BACKEND=supabase` (ใช้ฐานข้อมูลแทน Google Sheet) จะเพิ่มในเวอร์ชันถัดไป
